# ExamLayoutParser

**AI-Evaluated Exam Layout Verification Engine**

Automatically verifies scanned university exam papers against their JSON templates.
Detects student markings, assesses scan quality, and produces confidence scores.

## What It Does

```
Input: scanned_exam.png + template.json
           │
           ▼
    1. Scan Quality Analysis  → blur, rotation, brightness
    2. Anchor Detection       → 4 bullseye corner markers
    3. Perspective Correction → homography alignment
    4. Region Verification    → per-question bounding boxes
    5. Marking Detection      → student answer detection
    6. Confidence Scoring     → overall PASS/PARTIAL/FAIL
           │
           ▼
Output: verified_image.jpg + report.json
```

## Supported Question Types

| Type | Detection |
|------|-----------|
| `multiple_choice` | Circle fill detection |
| `multi_select` | Square fill detection |
| `matching` | Answer box content |
| `fill_blanks` | Answer box content |
| `open_ended` | Writing density |

## Quick Start

```bash
pip install opencv-python numpy

# Verify a student exam
python exam_verifier.py \
  --image examples/student_scan.png \
  --template templates/ICE101_midterm.json \
  --output output/

# Compare multiple scans
python compare_exams.py \
  --template templates/ICE101_midterm.json \
  --images examples/scan1.png examples/scan2.png

# Generate test variants (rotated, blurry, etc.)
python create_test_rotated.py \
  --image examples/blank_exam.png \
  --template templates/ICE101_midterm.json
```

## Template Format

Exams are generated by `iku-exam-generator` and produce JSON files with:
- Bullseye anchor positions (4 corners)
- Question bounding boxes
- Option positions (for MC questions)
- Answer box positions (for matching/fill-blanks)
